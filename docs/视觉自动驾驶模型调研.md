> 调研日期: 2026-05-17 | 目标: 给 CarlaAir 的地面车辆接入基于视觉输入的自动驾驶模型

| CARLA 仿真 | ✅ 运行中 | 端口2000，Town10HD地图 |

### 1.2 当前架构 vs 目标架构

```
当前 (非视觉):
  CARLA路网API → RouteFollowingDriver → VehicleControl
  车辆位置API ↗

目标 (视觉):
  车载RGB摄像头 → CNN模型 → VehicleControl
```

### 1.3 集成点

控制循环在 `env.py` 的 `_start_ego_control()` 中，以 8Hz 运行：

```python

speed = vehicle.get_velocity()

```

## 二、候选模型方案（按复杂度递增）

### 方案一：PilotNet (NVIDIA, 2016) ⭐ 首推

**最经典的端到端视觉驾驶模型，极简架构，适合作为第一个接入的baseline。**

| 项目 | 说明 |
|------|------|
| 输入 | 单帧 RGB 图像 (建议 200×66 或 320×240) |
| 输出 | steering angle (单值) 或 steering + throttle |
| 参数量 | ~250K (~3MB) |
| 推理速度 | 70+ FPS (GPU), 30+ FPS (CPU) |
| 架构 | 5层 Conv + 3层 FC，无复杂模块 |
| 训练数据 | 在 CARLA 中用 autopilot 跑几小时即可收集足够数据 |

**架构图：**
```
RGB (3×66×200) → Conv(24,5,2) → Conv(36,5,2) → Conv(48,5,2)
               → Conv(64,3,1) → Conv(64,3,1) → Flatten
               → FC(100) → FC(50) → FC(10) → FC(1) → steering
```

**优势：**
- 实现极其简单，~30行 PyTorch 代码
- 训练快（几小时在单GPU上）
- 有多个 CARLA 上的现成实现可参考
- 2024 年 Neurocomputing 论文验证在 CARLA 交通场景下仍有效

**劣势：**
- 只输出方向盘转角（需额外逻辑处理油门/刹车）
- 无路口决策能力（只能跟着路走）
- 泛化能力有限

**参考实现：**
- GitHub: `zcxixixi/carla-autonomous-driving-nvidia` — 含 CARLA 数据采集+训练脚本
- GitHub: `ManajitPal/DeepLearningForSelfDrivingCars` — 最简洁的 PyTorch 版本
- HuggingFace: `sergiopaniego/OptimizedPilotNet` — 含预训练权重

---

### 方案二：PilotNet* (Neurocomputing 2024)

**PilotNet 的升级版，同样是简单 CNN，但输出 steer + throttle + brake。**

| 项目 | 说明 |
|------|------|
| 输入 | RGB (66×200), 可选 speed 作为第4通道 |
| 输出 | steering, throttle, brake (3个值) |
| 参数量 | 与 PilotNet 相当 |
| 特点 | Dropout(0.1) 正则化, 弯道过采样, Albumentations 数据增强 |

**关键改进：**
- 在 PilotNet 基础上直接输出油门和刹车
- 已验证在 CARLA Town02 交通流场景中可安全跟车
- 数据集公开（~140K 张图片）
- 论文发表于 Neurocomputing 2024，方法可靠

**参考论文：** *Autonomous driving in traffic with end-to-end vision-based deep learning* (Neurocomputing, Aug 2024)

---

### 方案三：CILRS — Conditional Imitation Learning

**经典学术 Baseline，通过导航命令分支处理路口转向。**

| 项目 | 说明 |
|------|------|
| 输入 | RGB (200×88) + vehicle speed + navigation command (4选1) |
| 输出 | steer, throttle, brake, speed |
| 参数量 | ~30M (ResNet-34 backbone) |
| 架构 | ResNet-34 视觉编码器 + 速度拼接 + 4分支输出 |
| 训练框架 | DI-drive (OpenDILab) 提供完整 pipeline |

**架构核心思路：**
```
RGB → ResNet提取特征 → + [speed] → ┌─ 直行分支 → control
                                     ├─ 左转分支 → control
                                     ├─ 右转分支 → control
                                     └─ 跟道分支 → control
```

**优势：**
- 学术标准 baseline，对比结果有参考价值
- DI-drive 提供完整的 数据采集→训练→评测 流程
- 能处理路口转向

**劣势：**
- 需要导航命令输入（需从 CARLA 路网获取）
- 训练时间长 (~7-8h on RTX 2080Ti)
- 比 PilotNet 复杂一个量级

---

### 方案四：LEAD / TransFuser v6 — 纯视觉版本 (2025)

**SOTA 级别的纯视觉驾驶模型，有预训练权重可直接下载。**

| 项目 | 说明 |
|------|------|
| 输入 | 单/多相机 RGB |
| 输出 | waypoints → PID → steer/throttle/brake |
| 架构 | ResNet34 + Transformer 融合 |
| 参数量 | ~40M |
| 预训练权重 | ✅ HuggingFace 下载 |

**参考：** GitHub: `autonomousvision/lead`, Bench2Drive 得分 91.6 (vision-only)

## 四、推荐实施路径

### 阶段一：最简接入 (推荐从 PilotNet 开始)

```
1. 数据采集
   └── 用现有 RouteFollowingDriver 作为专家策略
   └── 行车时同步录制 RGB 图像 + 对应的 steer/throttle/brake
   └── 场景：Town10HD 中跑 30-60 分钟 ≈ 1-2万帧

2. 模型实现
   └── 在 code/models/ 下新建 pilotnet.py
   └── 纯 PyTorch，~30行网络代码
   └── 推理接口: predict(rgb_image, speed) → VehicleControl

3. 训练
   └── MSE loss 训练 steering 预测（可加 throttle/brake 头）
   └── 2-3小时在 GPU 上收敛

4. 集成
   └── 新建 VisionDriver 类，替换 RouteFollowingDriver
   └── 从 VehicleSensorRig 取 RGB 图像
   └── 调用模型推理 → 输出 VehicleControl
```

### 阶段二：增强

- 加入 navigation command 分支 → 升级到 CIL/CILRS 架构
- 增加数据增强 (亮度/对比度/噪声) 提高泛化性
- 加入 dropout 和弯道过采样 (参考 PilotNet* 论文)

### 阶段三：进阶

- 换用更大的 backbone (ResNet-18/34)
- 接入预训练权重 (如 LEAD vision-only checkpoint)
- 支持多相机输入

## 六、关键技术细节

### 6.1 图像预处理

CARLA 相机输出的 RGB 直接可用，只需：
- Resize 到模型要求尺寸 (如 200×66)
- 归一化到 [0,1] 或 [-1,1]
- (可选) YUV 色彩空间转换 (PilotNet 原论文使用)

### 6.2 油门/刹车控制策略

PilotNet 原论文只输出 steering。油门和刹车可用简单规则：

```python
target_speed = 8.0  # m/s
speed_error = target_speed - current_speed
if speed_error > 0:
    throttle = min(speed_error * 0.15, 0.5)
    brake = 0.0
else:
    throttle = 0.0
    brake = min(-speed_error * 0.3, 1.0)
```

或直接让模型输出 throttle 和 brake（PilotNet* 做法）。

### 6.3 训练数据采集策略

在 CarlaAir 中无侵入采集：

```python
# 每帧记录:
{
    "rgb": vehicle_sensor_rig.latest["rgb"],     # (360, 640, 3)
    "steer": expert_control.steer,               # float
    "throttle": expert_control.throttle,         # float
    "brake": expert_control.brake,               # float
    "speed": vehicle.get_velocity(),             # 3D vector → scalar m/s
}
```

弯道/复杂场景需要过采样（直道数据量过大，模型会偏向直行）。

## 七、总结

**推荐从 PilotNet 开始**。原因是：

1. 架构极简（5层Conv+3层FC），~30行 PyTorch 代码
2. PyTorch 2.11 已就绪，无额外依赖
3. CarlaAir 已有 `VehicleSensorRig` 提供 RGB 图像，无需新传感器
4. `RouteFollowingDriver` 可作为专家采集训练数据
5. 推理 70+ FPS，远超 8Hz 控制频率
6. 有大量 CARLA 上的成熟案例可参考
7. 后续可平滑升级到 CILRS 或更复杂模型
